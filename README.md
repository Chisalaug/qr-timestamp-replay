#qr-timestamp-replay
> 从一张二维码里读懂它的「心跳」，再把时间的节奏重新演一遍。
一个围绕 QR 二维码掩码 / 载荷 / 时间戳 的小实验台：既能把扫描件里藏着的掩码、纠错等级、版本和分段载荷读出来，也能顺着时间戳的脉络，把同族二维码按系统时间一张张复现、定时放映。命令行与本地 Web 界面两种形态，同一份解析与生成内核。
---
这是什么
很多时效类二维码，表面内容大同小异，真正变化的往往只是中间那一段时间戳或编号；而掩码（mask 0~7）、纠错等级、版本这些「格式骨架」则保持稳定。本项目做两件事：
读得懂：导入高清二维码图片，解析出载荷、掩码编号、纠错等级、版本号；多张同主题图片放在一起，自动分段、定位变化段，按时间戳排出先后顺序。
演得出：从样本里学出模板（固定业务段、时间戳段、掩码、纠错、版本），只替换时间戳就能复现同款二维码；Web 界面以系统时间为锚，按推算节奏实时刷新显示，模拟原系统的实效性刷新过程。
> 内置示例仅为占位形态 `EXAMPLE|<时间戳>|DEMO`；真实业务段、掩码与纠错全部以导入图片的解析结果为准，不会写死。
能力一览
模块	说明
单张解析	读取载荷、掩码（0~7）、纠错等级、版本；多级降噪 / 二值化兜底，应对纸面扫描、灰斑、浅模块等低清情况
批量解析	扫描目录内全部图片，汇总掩码 / 纠错 / 版本，分段定位变化段，按时间戳升序排出先后清单
模板学习	自动识别时间戳所在段，抽出前后固定段，并带上掩码、纠错、版本，形成可复用模板
同款复现	指定时间（日期时间 / Unix 秒 / 相对偏移均可），按模板拼装载荷并生成二维码；闭环回读校验四项参数
Web 实时放映	本地起服务、浏览器打开页面；支持周期对齐锚点或直接取系统时间两种模式，显示当前码、下一张与倒计时
打包发布	提供 PyInstaller 脚本，一键打包单文件 / 目录版独立 EXE
可以拿来做什么
二维码结构学习：观察版本、纠错等级与掩码如何写进格式信息，理解 BCH 纠错与掩膜图案的关系。
时效码规律分析：把一批样例导进来，看相邻时间戳的差值分布，推断刷新节奏（间隔不一致时会如实列出差值，不硬造周期）。
教学与演示：课堂或分享里对照展示「同一张骨架、不同时间戳」的同族二维码。
原型调试：为自己的实验项目生成一批带连续 / 指定时间戳的样例码，做扫码链路的对照测试。
解析工具旁证：掩码、纠错、版本读出后可直接回填给生成器，验证「读出来的参数能原样复现」这一闭环。
快速开始
环境
Python 3.8+（开发验证于 3.14）
依赖：`zxing-cpp`、`pillow`、`qrcode`；打包另需 `pyinstaller`
安装依赖
```bash
pip install -r requirements.txt
```
程序启动时若检测到缺依赖，命令行版与 Web 版都会给出安装引导，可选择自动安装后重启。
命令行版
```bash
python main.py
```
```text
[1] 单张图片解析：读取掩码、载荷、纠错等级
[2] 批量解析：读取文件夹内所有图片，推断先后顺序并学出时间戳模板
[3] 按时间戳生成二维码：只填时间，固定段/掩码/纠错照抄模板
[4] 退出
```
Web 界面版
```bash
python app_web.py
```
启动后自动打开浏览器页面（默认 `http://127.0.0.1:8765/`）。页面提供：多选图片上传、整文件夹选择、本地目录路径扫描；样本表、模板信息、相邻差值、刷新间隔与放映模式设置，以及实时二维码与倒计时。
打包成 EXE
```bash
# 单文件版
python build_web.py

# 目录版（启动更快，中文路径下可直接双击）
python build_web.py --onedir
```
命令行版对应打包脚本为 `build_exe.py`，用法一致。
> 已知限制：PyInstaller 单文件版在含中文 / 非 ASCII 字符的路径下双击可能报临时目录创建错误；可把 EXE 复制到纯英文路径运行，或改用目录版。
目录结构
```text
qr-timestamp-replay/
├── main.py          # 命令行交互主程序（解析 / 批量排序 / 模板生成）
├── app_web.py       # Web 本地服务 + 前端页面（实时放映）
├── build_exe.py     # 命令行版 PyInstaller 打包脚本
├── build_web.py     # Web 版 PyInstaller 打包脚本

```
实现要点
指定掩码生成：`qrcode.QRCode(..., mask_pattern=mask)` 显式传入掩码，关闭自动挑选，掩码直接写进格式信息；版本 + 纠错 + 载荷 + 掩码一致时，模块矩阵与原图逐模块相同。
掩码读取：优先取 `zxing-cpp` 结果 `extra['DataMask']`；未暴露时用内置几何兜底，从格式信息区取 15bit 做 BCH(15,5) 最小汉明距离反解。
时间戳分段：按 `| / - , ; 空格` 等分隔符拆段，优先识别像 Unix 时间戳的变化段，其次纯数字编号段，最后文本段。
实时推算：以最早样本时间戳为锚点，按设定间隔对齐当前序号；也可跳过周期、直接使用系统当前时间戳。
